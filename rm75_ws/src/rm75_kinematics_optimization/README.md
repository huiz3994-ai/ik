# RM75 kinematics optimization

Independent, offline RM75-6FB algorithms for Pinocchio FK/Jacobian, adaptive damped
least-squares IK, seven-axis nullspace joint centering, KDL comparison, tests and reproducible
benchmarks. This package does not publish robot commands and is not connected to `rm_driver`.

## Build and test

```bash
docker exec rm75_noetic bash -lc '
  source /opt/ros/noetic/setup.bash
  cd /root/rm75_ws
  catkin build rm75_kinematics_optimization
  source devel/setup.bash
  catkin run_tests rm75_kinematics_optimization
  catkin_test_results build/rm75_kinematics_optimization'
```

The CMake configure step expands the vendor xacro with `link7_type:=Link7_6fb`; it never
edits the vendor model. Pinocchio 2.7 is discovered through `pkg-config`.

## Isolated CasADi/Ipopt solver

```bash
./scripts/setup_casadi_venv.sh /tmp/rm75_casadi_venv
RM75_6FB_URDF=/absolute/path/to/rm75_6fb.generated.urdf \
  /tmp/rm75_casadi_venv/bin/python test/optimization_ik_test.py -v
```

The virtual environment is separate from ROS. `optimization_ik.py` creates the FK entirely
with CasADi symbolic operations and applies hard joint bounds through Ipopt. See the
2026-10-13 scenario report for the exact shared-sample benchmark commands.

## Benchmark

```bash
rosrun rm75_kinematics_optimization rm75_ik_benchmark \
  --count 1000 --seed 7506 --output /tmp/rm75_1000
rosrun rm75_kinematics_optimization rm75_ik_benchmark \
  --count 10000 --seed 7506 --output /tmp/rm75_10000
# Extended run (command supported, not run in phase one):
rosrun rm75_kinematics_optimization rm75_ik_benchmark \
  --count 100000 --seed 7506 --output /tmp/rm75_100000
rosrun rm75_kinematics_optimization plot_benchmark.py /tmp/rm75_10000.csv \
  --output /tmp/rm75_10000
```

The current scenario run additionally uses:

```bash
rosrun rm75_kinematics_optimization rm75_ik_benchmark --count 10000 --seed 7506 \
  --output /tmp/rm75_scenarios
/tmp/rm75_casadi_venv/bin/python scripts/optimization_ik_benchmark.py \
  --urdf /absolute/path/to/rm75_6fb.generated.urdf \
  --samples-csv /tmp/rm75_scenarios.csv --count 1000 --output /tmp/rm75_ipopt
```

Targets are generated by FK from legal samples. Seeds are independently sampled and never
reuse the target joint solution. A solve succeeds only at <=2 mm, <=2 degrees and inside all
hard limits. Raw CSV, JSON summary and plots from the executed runs are in
`benchmark/results`. See `docs/design.md` and `docs/benchmark-20261012.md` for conventions
and interpretation.
