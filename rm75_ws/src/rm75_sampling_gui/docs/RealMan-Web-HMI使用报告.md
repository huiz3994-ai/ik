# RealMan 高原寒区采样机器人 Web HMI 使用报告

报告日期：2026-10-24  
适用项目：`/home/zjh/project/RealMan`  
适用功能包：`rm75_sampling_gui`  
运行环境：ROS Noetic、Docker 容器 `rm75_noetic`、React/TypeScript、FastAPI

## 1. 报告目的

本报告说明 RealMan Web HMI 的部署、启动、页面功能、标准操作流程、安全边界、验证结果及常见故障处理方法。

本次升级参考 `ros2-smpling-robot-main` 的 GUI 功能，只补充 RealMan 原来缺失的部分。RealMan 已有的二维码五目标、Tool5 力控钻取、水质传感器、水泵、电机、控制租约和安全状态机均予以保留，没有用参考项目的 ROS2 桥接替换现有 ROS Noetic 控制链。

## 2. 本次新增内容

### 2.1 机器人状态页

- 增加“关节角 / 笛卡尔位姿”双页签。
- 关节角模式继续使用原有七轴目标预览与执行功能。
- 笛卡尔模式可输入 Link7 在 `base_link` 下的 X、Y、Z、Rx、Ry、Rz。
- 支持仅计算 IK 的离线预览；青色模型表示目标姿态，预览不会让机械臂运动。
- 支持将 IK 结果送入 RealMan 原有七轴安全执行链。
- 支持同步当前实际末端位姿。
- 支持加载零位、前伸、收拢等预设姿态。

单位约定：

| 参数 | 单位 | 说明 |
|---|---:|---|
| X、Y、Z | m | Link7 在 `base_link` 下的位置 |
| Rx、Ry、Rz | rad | 固定轴 XYZ RPY 姿态 |
| J1–J7 | rad；页面显示为 ° | 七轴关节位置 |

### 2.2 机器人控制页

侧栏新增“机器人控制”，包含：

- 启动和停止已有 Touch 遥操作；
- 显示控制模式、Touch 在线状态和机器人状态机状态；
- 选择并保存规划器与速度档；
- 一键执行预设笛卡尔姿态；
- 停止关节运动、终止工具任务；
- 工具端 24 V 上电与 0 V 断电；
- 最近 240 个 Fz 样本的实时曲线。

规划器与速度档保存在 `config/ui_settings.yaml`。当前 RealMan 的笛卡尔执行最终仍转换为七轴目标，并由现有 `joint_control_adapter` 决定真实轨迹和安全检查；界面设置不会绕过底层授权或改变底层安全阈值。

### 2.3 后端能力

新增接口：

| 方法 | 地址 | 功能 | 是否需要控制权 |
|---|---|---|---|
| POST | `/api/v1/kinematics/fk` | 七轴角度计算 Link7 位姿 | 否 |
| POST | `/api/v1/cartesian/preview` | 笛卡尔目标数值 IK 预览 | 否 |
| POST | `/api/v1/cartesian/execute` | IK 后进入原七轴安全执行链 | 是 |
| GET | `/api/v1/poses` | 读取预设姿态 | 否 |
| PUT | `/api/v1/poses/{index}` | 原子保存指定预设姿态 | 是 |
| GET | `/api/v1/settings` | 读取规划器和速度档 | 否 |
| PUT | `/api/v1/settings` | 保存规划器和速度档 | 否，仅修改界面配置 |

预设姿态保存在 `config/poses.yaml`，界面设置保存在 `config/ui_settings.yaml`。两个文件均采用临时文件加原子替换方式保存，避免写入中断后留下半截 YAML。

## 3. 启动前检查

### 3.1 软件检查

确认 Docker 容器存在：

```bash
docker ps --format '{{.Names}}\t{{.Status}}'
```

首次安装 Web Python 依赖：

```bash
docker exec rm75_noetic bash -lc \
  'python3 -m venv --system-site-packages /root/rm75_ws/.venv-rm75-web && \
   /root/rm75_ws/.venv-rm75-web/bin/pip install -r \
   /root/rm75_ws/src/rm75_sampling_gui/web/backend/requirements.txt'
```

修改前端源码后重新构建：

```bash
cd /home/zjh/project/RealMan/rm75_ws/src/rm75_sampling_gui/web/frontend
npm install
npm run build
```

### 3.2 真机检查

真机运行前必须确认：

1. 机械臂工作区无人且无障碍物；
2. 实体急停按钮可立即触及；
3. 示教器、拖动示教、Touch、力控及其他控制源处于停止状态；
4. 浏览器显示的实际七轴角度与真实机器人一致；
5. 控制器地址 `192.168.1.18:8080` 可访问；
6. 根据任务只选择一个互斥控制路径；
7. Tool5 钻土模式下，工具必须已经人工接触土壤。

## 4. 启动方式

网页只有一个正式启动命令：

```bash
/home/zjh/project/RealMan/rm75_ws/src/rm75_sampling_gui/scripts/start_sampling_web.sh
```

终端没有模式菜单或授权输入；执行唯一启动脚本后默认进入七轴关节控制路径，浏览器操作台直接提供以下路径：安全观察、七轴
关节控制、Z 力位 / Touch、QR / 轨迹桥、Tool5 钻取。网页切换路径时必须持有独占控制租约，
且基础栈、相机、QR、Touch/力控均已停止；切换动作只更新下一次启动组合，不会自动启动
机器人或发送运动指令。后台始终只允许一个运动命令源。

旧 `start_sampling_web_realtime.sh` 暂时作为无参数兼容包装保留，并转交统一
入口，不再包含另一套预检、授权、启动或清理逻辑。

浏览器地址：`http://127.0.0.1:8088`  
交互式 API 文档：`http://127.0.0.1:8088/api/docs`

如需更换端口：

```bash
RM75_WEB_PORT=8092 ./rm75_ws/src/rm75_sampling_gui/scripts/start_sampling_web.sh --mode simulation
```

停止服务时，在启动终端按 `Ctrl+C`，等待后端、HMI 管理的 ROS launch 和硬件任务正常退出。

## 5. 标准操作流程

### 5.1 建立控制权

1. 打开 Web HMI。
2. 检查顶部 WebSocket 状态为“实时”。
3. 检查是否显示正确模式：观察、仿真或真机。
4. 点击右上角“取得控制权”。
5. 等待按钮显示“控制权已就绪”。
6. 控制会话依靠浏览器 WebSocket 每 200 ms 续约；关闭页面、网络断开或心跳超时后会失去执行权限。

没有控制权时仍可查看状态、三维模型、参数和 IK 预览，但不能发送运动、工具、电机或水泵命令。

### 5.2 七轴目标操作

1. 进入“机器人状态”。
2. 选择“关节角”。
3. 点击“同步实际姿态”。
4. 使用输入框、滑块或 ± 按钮修改目标。
5. 观察青色目标模型与白色实际模型的差异。
6. 检查每个关节的目标、误差和限位余量。
7. 确认控制权已就绪。
8. 点击“执行七轴目标”。

编辑目标只改变离线预览。真正执行前，后端仍检查 URDF 限位、反馈新鲜度、控制源互斥、碰撞状态、授权开关、控制租约和轨迹跟踪。

### 5.3 笛卡尔目标操作

1. 进入“机器人状态”。
2. 选择“笛卡尔位姿”。
3. 点击“同步实际位姿”，以当前位置为编辑起点。
4. 修改 X、Y、Z、Rx、Ry、Rz；建议每次只做小幅修改。
5. 点击“IK 预览”。
6. 确认提示为“IK 预览完成”，并检查青色模型姿态。
7. 确认控制权和真机环境安全。
8. 点击“执行末端目标”。

若 IK 不收敛，后端会报告位置误差和姿态误差。默认接受阈值为位置不超过 6 mm、姿态合误差不超过约 4.6°。IK 预览不发布 ROS 控制命令。

### 5.4 一键预设姿态

1. 进入“机器人控制”。
2. 在“一键姿态”区域查看目标名称和 XYZ。
3. 先在“机器人状态”的笛卡尔模式中预览该目标。
4. 确认工作区安全并取得控制权。
5. 点击对应预设按钮执行。

初始预设包括零位、前伸和收拢。它们是配置目标，不代表所有现场环境中均无碰撞；真机执行仍以实时安全检查结果为准。

### 5.5 Touch 遥操作

1. 启动基础机器人栈并确认 Touch 节点在线。
2. 确保关节控制、独立力控、二维码执行和 Tool5 钻取没有占用机械臂。
3. 进入“机器人控制”。
4. 取得控制权。
5. 点击“启动 Touch 遥操作”。
6. 观察控制模式切换为 `teleop`。
7. 完成后点击“停止遥操作”。

若需要 Z 轴力位加触觉反馈，应在统一启动菜单中选择“Z 力位 / Touch”，完成实机确认后使用“实时力监控”页面中的专用按钮；该模式不能与普通 Touch 遥操作同时运行。

### 5.6 工具、电机、水泵和 Tool5

- 二维码取物：进入“二维码取物”，按识别、计算、预览、Dry Run、确认执行的顺序操作。
- 自主写点取物：进入“自主写点取物”，保存绝对 Link7 位姿，先 Dry Run，再确认执行。
- 水质与水泵：进入“采样设备”，确认 RS-485 和继电器在线后操作。
- DM-J4310：速度不得超过 1.0 rad/s，普通动作单次有界运行时长不得超过 60 s；Tool5 连续钻进由心跳看门狗与独立停止命令保护。
- Tool5：工具接触土壤后输入下降深度，启动取土；达到深度后 Z 进给停止并保持，电机继续旋转，必须由操作者点击停止旋转。

## 7. 安全机制

### 7.1 独占控制租约

- 同一时刻仅允许一个浏览器取得控制权。
- 控制租约必须绑定活动 WebSocket。
- 浏览器断开后租约过期，后端停止发布受保护心跳。
- 请求头使用 `X-RM75-Control-Session`，不能使用伪造或其他页面的会话。

### 7.2 控制路径互斥

以下真实运动路径不能同时授权：

- 七轴关节控制；
- trajectory bridge / 二维码取物；
- Z 轴力位遥操作；
- Tool5 力控钻取。

启动脚本检测到多个真实控制路径时会直接拒绝启动。

### 7.3 SAFE_STOP

软件急停会锁存 `SAFE_STOP`。锁存期间：

- 新运动命令被拒绝；
- 水泵只允许关闭；
- 电机只允许停止或读取状态；
- 工具 24 V 上电被拒绝；
- 必须在确认现场安全后，通过“故障诊断 → 执行受控恢复”解除。

软件急停不能替代实体急停。实体急停和现场隔离措施始终具有最高优先级。

### 7.4 不构成安全认证的内容

以下内容仍需现场验收，本报告不将其声明为已完成：

- 全七轴真实工作包络和负载测试；
- 浏览器断联到机械制动的最坏停止距离；
- 实体急停链和控制器急停回执；
- 完整真实环境 PlanningScene；
- 工具物体在位确认；
- Tool5 TCP 尖端标定；
- D435i USB 3 RGB-D 能力；
- 持载、土壤扰动和连续作业可靠性。

## 10. 常见故障排查

### 10.1 8088 端口已占用

现象：启动脚本提示 `127.0.0.1:8088 is already in use`。

处理：

```bash
docker exec rm75_noetic bash -lc "ss -ltnp | grep 8088"
```

正常停止原启动终端，或设置新的 `RM75_WEB_PORT`。不要直接启动多个真机控制实例。

### 10.2 页面一直显示正在连接

检查：

```bash
curl http://127.0.0.1:8088/api/v1/health
docker logs --tail 100 rm75_noetic
```

同时确认 `web/frontend/dist/index.html` 存在、后端依赖已安装。

### 10.3 无法取得控制权

可能原因：

- 当前为 OFFLINE 模式；
- 另一个浏览器占用租约；
- WebSocket 未连接；
- 旧页面仍保持心跳。

关闭其他页面并等待租约超时，随后重新取得控制权。

### 10.4 IK 未收敛

处理建议：

1. 点击“同步实际位姿”；
2. 从当前位姿开始小幅修改；
3. 减小位移和姿态变化；
4. 先调整位置，再逐步调整姿态；
5. 检查目标是否超出 RM75 工作空间或迫使关节接近限位。

### 10.5 点击执行返回 409

常见原因：

- 当前启动模式没有真实执行授权；
- 控制租约未绑定或已超时；
- 关节或 TF 反馈过期；
- MoveIt/FCL 检查失败；
- 其他控制源正在占用机械臂；
- SAFE_STOP 已锁存；
- 真机执行门禁尚未完成现场验收。

应查看页面提示、故障诊断和事件时间线，不应通过修改网页绕过拒绝原因。

### 10.6 前端修改后页面没有变化

重新构建并刷新：

```bash
cd /home/zjh/project/RealMan/rm75_ws/src/rm75_sampling_gui/web/frontend
npm run build
```

随后重启 Web HMI，并在浏览器执行强制刷新。

## 11. 建议的交付验收顺序

1. 观察模式检查所有状态和真实反馈；
2. 仿真模式练习控制租约、IK 预览、执行、急停和恢复；
3. 真机断使能或无运动条件下核对目标与实际数据；
4. 空载、低速、小角度单轴测试；
5. 空载、小位移笛卡尔测试；
6. 单工具 Dry Run；
7. 单工具低速真实取放；
8. 水泵和电机独立测试；
9. Tool5 接触土壤后的有界深度测试；
10. 记录每一步的日志、回执、停止时间和异常恢复结果。

任一步骤未通过时应停止后续验收，保存日志并定位原因。

## 12. 结论

RealMan Web HMI 已补充参考项目中缺失的机器人控制、笛卡尔预览/执行、预设姿态、规划器/速度档和快捷安全控制。新增功能复用了 RealMan 原有模型、状态机、独占控制租约和七轴安全执行链，没有引入任意 ROS topic、service、launch 或 shell 调用接口。

软件构建与仿真回归已通过。真机使用仍必须遵循启动授权、控制路径互斥、低速小步验证和实体急停优先原则。
