# 双向力反馈实机验证（2026-10-12）

## 实机条件

- 机械臂：RM75-6FB，`192.168.1.18:8080`
- 末端：六维力传感器下游安装 RGB 相机法兰支架
- 静态残余合力：约 2.1–2.5 N
- Touch：Geomagic Touch，真实设备力指令经
  `/rm75_touch_teleop/haptic_device_command` → `/touch_pubforce` →
  `/Geomagic/force_feedback`

## 确定性关节往返

仅启动 RM75 驱动，从当前关节角出发令第 7 轴以平滑轨迹执行
`+0.02 rad`（约 1.15°）并返回：

- 实际最大位移：0.019178 rad
- 最大关节跟踪误差：0.007147 rad
- 峰值合力：2.412 N
- 峰值合力矩：0.102 N·m
- 未触发急停

## 双向位置耦合复测

使用隔离的合成 Touch 输入给生产遥操作节点施加机器人 +X 方向 6 mm
阶跃，真实 Touch 仅接收力输出。测试中禁用接触力控，保留六维力、输入超时、
关节误差和急停保护。

初始 40 N/m 参数：

- 最大笛卡尔跟踪误差：5.992 mm
- 位置耦合力：0.200 N
- Touch 实际接收峰值：0.193 N

调至 60 N/m 后复测：

- 最大笛卡尔跟踪误差：5.993 mm
- 位置耦合力：0.300 N
- Touch 实际接收峰值：0.267 N
- 最大关节跟踪误差：0.062080 rad（低于测试保护值 0.08 rad）
- 峰值合力：2.509 N
- 峰值合力矩：0.103 N·m
- 返回后的最大关节偏差：0.000401 rad
- 未触发急停

`/Geomagic/force_feedback` 的峰值向量与
`/rm75_touch_teleop/haptic_device_command` 完全一致，确认软件计算出的阻力已经
到达真实 Touch 驱动，而不是只停留在诊断话题。

## 落地参数与行为

- 正式触觉入口使用 60 N/m 位置刚度，输出向量范数仍限制为 0.5 N。
- 1 mm 以内位置误差无位置弹簧力；误差超过 1 mm 后连续增加。
- RM75 被阻挡时，Touch 会先获得与从机未跟随量对应的反向阻力。
- 关节实际值与已发送命令的偏差超过 0.15 rad 时进入 `SAFE_STOP`，防止解除阻挡后追赶过大的累积目标。
- `SAFE_STOP`、反馈超时或松开按钮时不会继续输出位置耦合力。
- 正式自由空间触觉入口禁用土壤接触力控，避免相机法兰的约 2.5 N 静态残余力靠近 3 N 接触阈值造成模式误切换；六维力安全保护仍保持启用。
