- [官方 UDP 协议](https://develop.realman-robotics.com/robot4th/json/udpConfig/)定义：0=传感器，1=当前工作，2=当前工具。原反馈为0，采样入口已改成1，并同步 `expected_force_coordinate: 1`。本次 World 与基座重合，所以采用 base_link；如果工作坐标变化，必须重新核对。

第二次完整记录确认了力符号：基座 +Z 施力对应原始 World Fz 正向增大，松手后恢复到约 −1.30 N，因此实机配置采用 `force_sign: -1.0`。本次人工施力峰值约 45.59 N；后续接触验证应使用低力调试配置和测试材料，不应让机械臂对操作者的手执行闭环恒力。

## 终端准备

```bash
docker exec -it rm75_noetic bash
source /opt/ros/noetic/setup.bash
source /root/rm75_ws/devel/setup.bash
```

启动前先检查是否仍有 ROS graph：

```bash
rosnode list
rosparam get /rm75_touch_teleop/motion_enabled
rostopic echo -n 1 /rm75_touch_teleop/active
```

观察模式应为 false / false。`SAFE_STOP` 表示保护已锁存，不表示控制器正在运动。观察模式下即使手动施力超过软件阈值，也只记录并锁存状态，不再向驱动发布 Emergency_Stop；因为该模式从未发送运动指令。

正常结束使用启动脚本打开的 launch 时，在原终端按 Ctrl+C。若终端已经丢失，可用：

```bash
rosnode kill /rm75_touch_teleop
```

该节点在 launch 中为 required，退出会触发同一 launch 清理其子节点。RealSense、视觉等节点可以继续使用同一个 ROS master；三个实机启动脚本只拒绝仍能响应的 `/rm75_touch_teleop`、`/rm_driver`、Geomagic 驱动或 Touch 辅助节点。`rosnode list` 中残留但无法 ping 通的旧名字不会阻止启动。

## 2. 普通空载遥操作

本台实机入口现在默认使用已核实的6FB模型和World坐标力反馈：

```bash
/root/rm75_ws/start_rm75_touch_real_6f.sh enable_motion:=true
```

此入口是普通位置遥操作，不是恒力采样；保留原35 N合力/5 N·m保护。灰键按住控制平移，白键可独立按住控制姿态；松开任一键会冻结对应目标，两键都松开后退出控制。Touch映射：机械臂X=−Touch Z，Y=−Touch X，Z=Touch Y。确保手臂/工具周围有空间后，从毫米级小动作开始。没有完成本次动态试动，不能据静态检查宣称运动方向和跟踪已经实机验收。

## 3. 力控必须先完成符号核验

保持调试观察模式及灰键松开，给法兰一个已知基座方向的小外力并记录变化，移除力后检查回零。不要在主动运动开启时用手完成该标定。

向下插入时，环境对机械臂的接触反力通常向上。本控制器使用“插入载荷负值”的约定：

- 如果已知向上外力对应原始 World Fz 增大为正，设置 `force_sign: -1.0`。
- 如果已知向上外力对应原始 World Fz 变负，设置 `force_sign: 1.0`。
- 不能只看静止时正负零漂决定符号；不要仅为让程序运行而设置 `force_frame_verified: true`。

在确认该对应关系、回零和坐标无误后，才将调试 YAML 的 `force_frame_verified` 设 true。`force_motion_sign` 保持+1对应负误差向下，最终仍需小载荷接触确认负反馈。配置在启动时读取，修改后重启生效。

完成核验且具备受限接触测试条件后，低力入口为：

```bash
/root/rm75_ws/start_rm75_commissioning_real.sh enable_motion:=true
```

先用低力调试配置验证接近、3 N接触触发、−10 N保持、水平移动、松键退出和保护恢复。不要让空法兰直接撞击硬表面，不应在手接触法兰时开启主动运动测试。安装真实采样器后重新核实TCP、负载/重力补偿及测力零点。

## 4. 正式 −50 N 采样

只有在低力接触实测和装工具配置完成后，才把已验证的坐标/符号应用到 `rm75_touch_sampling_real.yaml`，并采用：

```bash
/root/rm75_ws/start_rm75_sampling_real.sh enable_motion:=true
```

接触后Z不再跟随Touch；X/Y与姿态继续跟随。自动退出条件为力低于release_threshold，不能靠向上推手柄Z直接拔出。主动拔出应先退出力控，按已验证的受控卸载流程处理。
