# RM75 + Geomagic Touch 采样力位混合控制

适用：ROS1 Noetic，当前 RealMan 工程及 `rm75_noetic` 容器。主控制节点仍为 `rm75_touch_teleop_node`，保持既有 Touch → Cartesian → 七轴 IK → 关节限速 → 输出链路。没有增加第二个机械臂控制发布节点。

## 2026-10-04 实机核对更新

当前连接的控制器自报 `RM75-6FB`。所有本台实机脚本固定使用仓库中的 `Link7_6fb`（末端长度 0.1612 m），不再提供 6F 模型回退。

采样实机入口现默认 `udp_force_coordinate:=1`，YAML 的 `expected_force_coordinate: 1` 与之匹配。已只读查询当前工作坐标 `World` 为零偏移、工具 `Arm_Tip` 为零偏移且负载为零。编号含义经[官方 UDP 文档](https://develop.realman-robotics.com/robot4th/json/udpConfig/)确认：0=传感器、1=当前工作、2=当前工具。以后改变工作坐标系需重新核对配置，编号相同并不保证工作坐标未改变。

新增低力调试入口 `/root/rm75_ws/start_rm75_commissioning_real.sh`（默认不使能运动），目标 −10 N，力上限 20 N，Z 限速 2 mm/s。正式采样仍使用原 −50 N 采样 YAML。实机力符号和有载稳定性必须单独验证。普通、调试和正式三个启动脚本只拒绝存活的 RM75/Touch 控制节点；RealSense 等节点可以继续复用已有 ROS master。

## 1. 文件与功能

- `src/rm75_touch_teleop_node.cpp`：新增三状态、力反馈坐标变换、Z 外环、故障锁存及监测输出；普通模式仍使用既有映射和 IK。
- `include/rm75_touch_teleop/hybrid_force_control.h`：可独立测试的状态和积分逻辑。
- `config/rm75_touch_sampling_real.yaml`：实机采样；JointPos 输出，默认不使能运动，力坐标未验证时拒绝使能。
- `config/rm75_touch_sampling_sim.yaml`：仿真采样；轨迹输出，使用独立 `/sampling_sim/wrench`。
- `src/sampling_soil_sim_node.cpp`：从仿真实际关节位置经 FK 计算 Link7 深度的弹簧/阻尼测力模型。
- `launch/sampling_sim.launch`、`launch/sampling_real.launch`：两种采样入口。
- 工作区根目录 `start_rm75_sampling_sim.sh`、`start_rm75_sampling_real.sh`：便捷启动脚本。
- `test/hybrid_force_control_test.cpp`、`test/hybrid_force_control.test`、`test/hybrid_force_control_ros_test.py`：控制逻辑及隔离 ROS 行为测试。

仿真和实机不可同时运行在同一个 ROS master。模拟力只发布到 `/sampling_sim/wrench`，不伪装为实机传感器。实机脚本允许相机/视觉节点共用 ROS master，但会拒绝存活的 RM75/Touch 控制节点；不会自动停止其他程序。

## 4. 仿真采样

启动容器内的新脚本：

```bash
/root/rm75_ws/start_rm75_sampling_sim.sh
```

无图形环境可用：

```bash
/root/rm75_ws/start_rm75_sampling_sim.sh gazebo_gui:=false
```

启动后已有初始化节点会在 Gazebo 内移动到 forward 姿态，约 3 秒。这是原仿真行为；不用于实机。等待初始化结束，再在另一个已 source 的容器终端执行：

```bash
rosservice call /sampling_soil/set_surface '{}'
```

默认土壤力在校准前关闭，避免初始化姿态运动误触发超力；校准后启用。若明确需要固定表面，可传 `surface_enabled:=true surface_z:=已知高度`，并自行保证初始位姿不穿入表面。

成功响应会将模拟土壤表面设置在**当前 Link7 下方 10 mm**。松开灰键执行此操作；不要在接触力控期间移动模拟土壤表面。默认刚度 5000 N/m、阻尼 20 N·s/m，可通过 launch 的 `stiffness`、`damping` 参数调整。

操作顺序：

1. 按住灰键，使能位置遥操作。机械臂 X = −Touch Z、Y = −Touch X、Z = Touch Y。
2. 缓慢靠近模拟土壤。超过 10 N 且持续达到去抖时间后，进入 CONTACT_MODE。
3. 保持灰键。Touch Z/X 继续控制机械臂 X/Y；Touch Y 对机械臂 Z 的控制在接触模式被忽略。白键可独立按住控制姿态，无需同时按灰键。
4. 力目标逐渐过渡至 −50 N。5000 N/m 理想弹簧下，对应约 10 mm 静态压入深度。
5. 松开灰键即冻结位置目标并退出接触力控；若白键仍按住，只继续更新姿态。两键都松开后停止发布控制命令。退出接触会重新建立 Z 基准，不追赶被忽略的手柄 Z 位移。

**仿真范围**：这是用 Gazebo 关节运动驱动的解析土壤测力闭环，不是 Gazebo 接触动力学插件，不在 Gazebo 中施加反作用力，也不模拟破土、塑性、颗粒、摩擦、低温或真实传感器噪声。它适合检查模式、力收敛和通信故障，不能作为真实冻土稳定性证明。默认不会显示实体土壤块，表面高度可从 `/sampling_soil/surface_z` 读取。

Gazebo 暂停后不产生新的模拟力；墙钟看门狗仍工作并退出控制。恢复仿真后需松开并重新按灰键。

## 5. 实机采样：先配置测力坐标

配置文件：`/root/rm75_ws/src/rm75_touch_teleop/config/rm75_touch_sampling_real.yaml`。

先启动观察模式：

```bash
/root/rm75_ws/start_rm75_sampling_real.sh
```

另一个容器终端：

```bash
source /opt/ros/noetic/setup.bash
source /root/rm75_ws/devel/setup.bash
rosrun rm75_touch_teleop check_rm75_real_6f.sh
rostopic echo /rm_driver/Udp_Coordinate
rostopic echo /rm_driver/UdpSixZeroForce
rostopic echo /rm75_touch_teleop/force_z
```

`Six_Force` 没有 Header，接收端使用墙钟接收时间。驱动已经将数据转为 N、N·m，不能再次除以 1000。驱动的 UDP 坐标编号仅用于一致性检查，**不会自动替你判断该编号对应哪个空间坐标系**。

必须按设备当前配置设置以下字段：

| 参数 | 含义 |
|---|---|
| `expected_force_coordinate` | 必须与 `/rm_driver/Udp_Coordinate` 相同，且与实际驱动 `udp_force_coordinate` 配置一致；实机不允许设为 −1 |
| `force_frame` | 消息力分量所属的 URDF link 坐标系；默认 `base_link` 是待验证配置，不是对编号 0 的解释 |
| `force_frame_rotation_rpy` | 将原始传感器坐标旋转到 `force_frame` 的固定 RPY，单位 rad；旋转顺序 Rz·Ry·Rx |
| `force_sign` | +1 或 −1；把原始反馈转换为本控制器“向下插入载荷为负”的约定 |
| `force_motion_sign` | +1 或 −1；默认 +1 表示负力误差产生向下 Z 速度；必须形成负反馈 |
| `force_frame_verified` | 完成坐标、方向、负载补偿核验后改为 true；false 时只允许自由空间 POSITION_MODE，检测到接触立即 SAFE_STOP |

支持 `force_frame: Link7` 等随关节转动的 link，程序使用新鲜关节反馈计算旋转到 base_link。若传感器坐标与 Link7 不同，填入已知的安装旋转。若控制器使用自定义工作坐标系，需要先匹配其旋转；不要仅因数字编号相同就填 base_link。力矩保护保留原测量点的模长，未将力矩平移到采样尖端。

安装采样器后应依据设备流程确认负载/重力补偿及零点，本程序不会自动清零。改变姿态时应确认补偿后的外力不会被工具自重显著污染。当前控制点是 **Link7**，不是带工具长度偏置的尖端；旋转采样器时尖端轨迹不同。需要真实尖端控制时，应先为已知工具几何添加正确 TCP，并验证 IK 支持，不能把 Link7 等同于工具尖端。

确认上述配置后，结束观察 launch，再启动：

```bash
/root/rm75_ws/start_rm75_sampling_real.sh enable_motion:=true
```

若设备采用其他 UDP 坐标编号，同时在 YAML 修改期望值并传入相应编号，例如使用已核实且与基座对齐的当前工作坐标系编号 1：

```bash
/root/rm75_ws/start_rm75_sampling_real.sh enable_motion:=true udp_force_coordinate:=1
```

启动时机械臂不会自动移动；仍需新鲜的 Touch、增量、Joy、关节、力和坐标反馈，且按下灰键才开始控制。先做低速、低载荷受限接触验证，再使用 −50 N 目标。若修改为较低目标，必须同时满足 `release_threshold < contact_threshold < abs(desired_force) < force_limit`。

默认采样参数并非经过实机辨识的稳定性保证。硬件停止延迟、负反馈方向、工具负载及真实土壤刚度必须现场验证；本次代码交付不执行实机运动。

## 6. 控制规律与参数单位

状态：POSITION_MODE、CONTACT_MODE、SAFE_STOP。`active=false` 表示未使能，即使模式名称为 POSITION_MODE 也不会发运动指令。

接触后的力控制是限速速度型外环：

`v_z = clamp(force_motion_sign * force_gain * (ramped_force - filtered_Fz), ±max_z_velocity)`

再根据本周期 dt 生成 Z 增量。**force_gain 单位为 m/(N·s)，不是原始直接位置补偿公式的 m/N**。直接用 0.002 m/N 会让 50 N 误差对应 100 mm 修正，本实现没有采用该公式。Touch Y 在接触期间被忽略；目标力渐变、限速及跟踪约束避免持续累计过大的未执行目标。

| 参数 | 默认 | 含义 |
|---|---:|---|
| `desired_force` | −50.0 N | 采样目标；当前实现要求负目标 |
| `contact_threshold` / `release_threshold` | 10 / 5 N | 按过滤后 Fz 绝对值判断，滞回防抖 |
| `contact_debounce` | 0.06 s | 接触/释放持续条件时间 |
| `force_gain` | 0.002 m/(N·s) | 速度型力外环增益 |
| `force_limit` | 100 N | 未滤波 base Z 力超限立即锁停 |
| `max_external_force` | 100 N | 原三轴合力保护仍有效；与 Z 限制并行 |
| `max_external_torque` | 5 N·m | 原三轴力矩模长保护 |
| `max_z_velocity` | 0.010 m/s | CONTACT_MODE 下 Z 指令速度上限 |
| `max_z_step` | 0.0004 m | 单周期 Z 指令增量上限 |
| `max_force_travel` | 0.05 m | 相对本次接触点的最大 Z 行程，超过锁停 |
| `max_z_tracking_error` | 0.005 m | Z 指令与反馈误差约束 |
| `max_joint_tracking_error` | 0.15 rad | 关节指令与反馈误差超过锁停 |
| `force_ramp_rate` | 20 N/s | 接触力向目标力过渡的最大斜率 |
| `force_filter_tau` | 0.03 s | 力低通时间常数；超力保护不经过滤波 |
| `force_deadband` | 1 N | 力误差死区 |
| `force_feedback_timeout` | 0.25 s | 力与坐标反馈接收超时 |
| `max_joint_acceleration` | 1.0 rad/s² | 七轴 QP 加速度上限 |
| `min_control_dt` / `max_control_dt` | 0.001 / 0.04 s | 实测单调控制周期的有效范围 |
| `max_ee_linear_velocity` / `max_ee_angular_velocity` | 0.08 m/s / 0.40 rad/s | Touch 目标变化上限 |
| `qp_posture_weight` | 0.08 | 实测 Jacobian 零空间姿态保持权重 |
| `qp_soft_limit_margin` | 0.20 rad | 七轴软限位速度阻尼区 |
| `qp_timeout` | 0.002 s | 盒约束 QP 求解超时；失败立即 SAFE_STOP |

保留原配置中的 Touch 比例、最大手柄位移、关节速度和模型关节限位。CONTACT_MODE 的手柄位移范围检查忽略手柄 Z 对应分量，但仍限制水平分量。

上述 Z 速度限制仅用于 CONTACT_MODE；自由空间仍按原位置遥操作逻辑。所有参数在节点启动时读取，运行期间 `rosparam set` 不会动态更新控制器，需要重启生效。

## 7. 停止、故障恢复与拔出

以下事件停止指令发布：

- 原始 Z 力、合力或力矩超过上限；NaN/Inf 力数据。
- 力、坐标、Touch pose、Joy、实际采用的增量或关节反馈超时。
- 坐标编号不匹配、关节跟踪误差过大、Z 行程超限。
- QP 超时、不可行、KKT/数值异常或输出校验失败时，不发布该周期目标并立即进入 SAFE_STOP；没有 KDL/DLS 无约束回退。

SAFE_STOP 锁存，不会因为反馈恢复就自动运动。实机在故障时额外向既有 `/rm_driver/Emergency_Stop` 发布一次 Empty，请求 `Move_Stop_Cmd()`；它不是硬件急停，也不代表已收到停稳确认。仿真停止新轨迹发布后，控制器可能完成已收到的短轨迹。程序故障、主机断电或通信完全中断仍需要设备侧的停止/看门狗机制。

恢复：排除故障，确认反馈正常，**松开灰键，再重新按下**。超力尚未解除时不能重新使能。禁止强行绕过保护继续压入。

自动释放条件是力低于 5 N，**不是向上推 Touch**。接触期间 Touch Y 被屏蔽，所以主动拔出应先松开灰键并停止采样，再切换到经过合适力阈值配置的普通位置遥操作进行受控拔出。默认普通 35 N 上限可能在仍有 −50 N 负载时拒绝使能；应先按现场流程卸载或使用专门验证过的拔出配置。本版本没有新增带负载自动拔出或忽略超力的旁路。

ROS 测试使用 `/test/...` 指令话题与合成关节反馈，不启动真实驱动或 Touch。覆盖两种输出、接触时忽略 Touch Y、水平移动、退出接触连续性、超力锁存、各输入断流、非法力、坐标不匹配、IK 失败和普通模式无力反馈运行。纯控制测试覆盖两种采样率下的理想弹簧收敛、限幅与不提交积分。
