日期：2026-10-01。环境：现有 `rm75_noetic` 容器，ROS Noetic、MoveIt KDL 七轴 IK、现有 RM75 Gazebo 模型。

## 验证范围

1. 编译 `rm75_touch_teleop` 及依赖通过。新增两个 C++ 可执行文件成功链接。
2. 纯逻辑测试：原有 2 个映射测试和新增 5 个混合力控测试通过。新增覆盖滞回与去抖、原始超力越过滤波、NaN、限速/行程/跟踪限制、失败时不提交状态、参数拒绝，以及 50/100 Hz 理想弹簧收敛。
3. 隔离 ROS 集成测试：真实 MoveIt IK + 合成关节反馈；分别验证 JointPos 和 JointTrajectory 输出。未启动实机驱动，所有指令和停止请求重映射至 `/test/...`。
4. ROS 集成场景覆盖：自由空间控制、接触切换、接触时忽略手柄 Z、X/Y 与白键姿态控制、释放后 Z 连续与恢复跟随、关节指令步长、超力锁存、数据恢复不自动运动、松键重按恢复、力/pose/Joy/增量/关节/坐标断流、NaN 力、坐标编号变化、不可达目标导致 IK 停发与持续失败锁停、普通模式无需力反馈。
5. Launch/package XML、Python 测试脚本语法、两个新启动脚本 bash 语法检查通过。

## 尚未验证

- 没有使能或移动真实 RM75；JointPos 路径仅通过重映射后的集成测试。
- 未现场确认实际 UDP 力坐标编号的语义、传感器安装旋转、力符号、采样器负载/重力补偿。
- 没有验证真实 CAN-FD 停流和 Move_Stop_Cmd 的制动延迟、通信失效停止能力。
- 没有模拟冻土破坏、颗粒接触、摩擦、低温或柔性结构；土壤节点是解析传感器模型，不是物理接触插件。
- 当前控制点为 Link7，未新增采样工具尖端几何；沿用原 IK 范围检查，没有新增环境碰撞规划。

因此实机 YAML 保留 `force_frame_verified: false` 和默认不使能运动，需依照使用说明完成设备配置后使用。
